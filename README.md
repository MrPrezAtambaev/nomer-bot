# nomer-bot

Телеграм-бот `@akyl_nomer_bot`: карточка госномера с nomer.srs.kg и сообщения, когда номер выходит без аукциона.

- Пришли номер (`888 KYH`, `01 777 LVS`) — картинка номера, статус, график торгов и дата выхода без аукциона.
- «🔔 Следить» — напоминания за 3 часа и за 10 минут, сообщение в минуту выхода, брони, продажа.
- Три буквы (`EEF`) — вся серия; три цифры (`777`) — все номера с этими цифрами: свободные, забронированные,
  на торгах и между торгами. Длинный список листается кнопками.
- `/sub 777`, `/sub HAH` — любые свободные номера без аукциона по маске. `/list`, `/mode`.
- `/region` — регион по умолчанию для чата (при первом `/start` бот спрашивает сам). Разово другой регион —
  `02 888 KYH`, `02 EEF`, `02 777`.

## Запуск

```bash
echo 'BOT_TOKEN=...' > .env && chmod 600 .env
python3 bot.py                              # бот и слежение
python3 bot.py card <chat_id> 888KYH        # разово прислать карточку
```

Нужен Python 3.9+; Pillow — только для картинки (без него карточка уходит текстом). Состояние — `data/state.json`
(`DATA_DIR` меняет папку). Время — Asia/Bishkek независимо от часового пояса машины.

Docker: `docker build -t nomer-bot . && docker run -d --restart=always -e BOT_TOKEN=... -v nomer-bot:/data nomer-bot`.
Railway: сервис из `Dockerfile` (`railway.json`), том на `/data`, переменная `BOT_TOKEN`; выкат — `railway up`.

## Как устроено

| Файл | Что делает |
|---|---|
| `srs.py` | страница номера (без сессии, метки на кыргызском), списки свободных и торгов по маске (JSF-сессия), общий запас открытых соединений |
| `forecast.py` | правило отсечки: первые торги цикла + 3 месяца, новые торги по понедельникам, выход в 00:00 |
| `card.py` | карточка: статус, график, важные моменты; сравнение снимков → сообщения |
| `render.py` | виджет (HTML, Bot API 10.4) и PNG |
| `bot.py` | Telegram, команды, цикл слежения |

Частота проверок номера: обычно раз в 10 минут; за 10 минут до важного момента (выход в 00:00, срок оплаты брони) —
раз в 30 секунд; с −45 с до +3 мин — раз в 2 секунды; дальше до +15 мин — раз в 10 секунд. На весь бот не больше
4 запросов в секунду к порталу.

Виджеты: Telegram пока пускает к `sendWidget` не всех ботов (`INPUT_MEDIA_WIDGET_NOT_ALLOWED`). Бот пробует виджет
раз в 6 часов и до тех пор шлёт картинку.
